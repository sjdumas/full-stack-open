# Rate Repository App

This project contains a mobile application for rating various GitHub repositories. With this app, you can do the following:

- Browse GitHub repositories
- View individual repository details and reviews
- Create new reviews on existing repositories

## Built With

This application was created using the following technologies:

- React Native
- Expo
- GraphQL API (as the backend)
